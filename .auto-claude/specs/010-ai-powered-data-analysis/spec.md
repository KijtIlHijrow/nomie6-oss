# AI-Powered Data Analysis

Enhanced Ollama/AI integration that allows natural language queries about user data, generates personalized insights, and helps users explore their data through conversation.

## Rationale
Builds on existing AI query integration with Ollama. Differentiates from competitors by offering local AI analysis without sending data to cloud services. Makes data exploration accessible to non-technical users.

## User Stories
- As a curious user, I want to ask 'What affects my mood the most?' and get an answer so that I learn without manual analysis
- As a privacy-conscious user, I want AI analysis without sending data to the cloud so that my data stays private

## Acceptance Criteria
- [ ] Users can ask natural language questions about their data
- [ ] AI provides personalized insights based on tracking history
- [ ] All processing happens locally via Ollama (no cloud)
- [ ] AI can suggest new things to track based on goals
- [ ] Clear indication when AI is generating vs showing real data
