# Automated Insight Discovery

Proactive system that automatically surfaces interesting patterns, anomalies, and trends in user data without requiring manual exploration. Weekly insights digest highlighting notable discoveries.

## Rationale
Exist.io's strength is automatic correlations - Nomie should offer similar value for free. Reduces effort required to benefit from tracking data. Addresses user goal of understanding patterns in daily life.

## User Stories
- As a busy user, I want insights surfaced automatically so that I benefit from tracking without analysis effort
- As a pattern seeker, I want to be notified of interesting trends so that I don't miss important changes

## Acceptance Criteria
- [ ] System identifies significant correlations automatically
- [ ] Anomalies flagged (e.g., 'Your sleep was 2 hours less than average this week')
- [ ] Trend detection (e.g., 'Your mood has been improving over the past month')
- [ ] Weekly insights summary notification/email
- [ ] Insights can be dismissed or saved for reference
