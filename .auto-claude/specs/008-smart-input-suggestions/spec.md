# Smart Input Suggestions

Context-aware suggestions in the log input that learn from user patterns. Suggests relevant trackers based on time of day, location, recent activity, and historical patterns.

## Rationale
Makes the natural language input smarter and faster. Addresses the gap between Apple Health's automatic data and manual entry by reducing cognitive load of remembering what to track.

## User Stories
- As a user, I want Nomie to suggest my morning trackers when I open it at 7am so that I don't forget anything
- As a regular tracker, I want my typical values pre-filled so that logging is faster

## Acceptance Criteria
- [ ] System learns from user's tracking patterns over 7 days
- [ ] Morning entries suggest morning-related trackers
- [ ] Suggestions show typical values based on historical data
- [ ] Users can disable suggestions if preferred
