# Create CONTRIBUTING.md with development setup and guidelines

## Overview

The project lacks a CONTRIBUTING.md file which is essential for open-source projects. New contributors have no guidance on development workflow, coding standards, commit conventions, testing requirements, or how to submit pull requests.

## Rationale

As an open-source project (nomie6-oss), clear contribution guidelines are critical for community engagement. The README mentions coding rules but doesn't provide practical setup steps. The project uses commitizen/commitlint for commits but this isn't documented anywhere for new contributors.
